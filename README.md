# AI Суфлер для Zoom (Push-to-Talk)

Программа перехватывает системный звук на Windows, распознает речь через Groq Whisper и выдает краткий ответ в полупрозрачном окне поверх всех программ. Также поддерживается ручной ввод текста.

## Требования
- Windows 10 / 11 (я думаю понятно, конечно скорее всего оно и на линуксе работает, но сумневаюсь что кому то пригодится это там)
- Python 3.12 (https://www.python.org/downloads/release/python-31210/)
- Бесплатный API-ключ с сайта console.groq.com

## Установка библиотек
Откройте командную строку (cmd) и выполните команду:

pip install pyaudiowpatch openai numpy keyboard

Если установлено несколько версий Python, используйте:

py -3.12 -m pip install pyaudiowpatch openai numpy keyboard

## Получение API-ключа
1. Перейдите на https://console.groq.com и войдите в аккаунт.
2. Откройте раздел API Keys.
3. Нажмите Create API Key и скопируйте ключ (начинается на gsk_).

## Запуск и использование
1. Запустите файл с .py
2. При первом запуске вставьте свой API-ключ Groq и нажмите "Сохранить и продолжить". Ключ сохранится в файл groq_key.txt рядом со скриптом, повторно вводить его не нужно.
3. Голосовой запрос: зажмите синюю кнопку в окне программы (или клавишу F9), пока говорит преподаватель. Отпустите кнопку, чтобы получить ответ.
4. Ручной запрос: введите или вставьте вопрос в нижнее текстовое поле и нажмите Enter (или кнопку отправки справа).
5. Смена ключа: нажмите кнопку с иконкой ключа в правом верхнем углу окна.

если не работает по звуку измените звуковое устройство
